# Как пользоваться TutorSpace

1. Откройте опубликованную ссылку: сначала пройдет проверка подключения, затем появится экран входа. Нажмите «Продолжить с ChatGPT» или «Войти в TutorSpace», если аккаунт уже найден. Откроется главная страница. Сайт приватный; пароль запрашивает только ChatGPT при необходимости.
2. Добавьте ученика: имя, класс, цель и часовую ставку. Учебный пример открывается отдельно через нижний пункт меню. В нем есть явная плашка «Это учебный пример» и кнопка «В мое пространство». Ранее созданные демонстрационные записи сохранены, но не смешиваются с настоящими учениками, расчетами и заданиями.
3. Откройте «Расписание». По умолчанию видны ближайшие занятия списком. «Прошедшие» включает историю месяца. Кнопки со стрелками переключают месяцы, «Сегодня» возвращает к текущему. Есть виды «Неделя» и «Месяц», мини-календарь для выбора дня и фильтр ученика. В месяце запланированное занятие можно перетащить на другую дату; перенос завершится только после сохранения формы.
4. Нажмите «Новое занятие» или плюс в ячейке даты. При ставке 800 ₽/час стоимость 60 минут составит 800 ₽, 90 минут — 1 200 ₽. Сумму можно скорректировать до проведения.
5. Для регулярных уроков включите повторение: понедельник и пятница выбраны заранее. Укажите последнюю дату. При временном конфликте система предложит выбрать другое время; частичная серия не сохраняется.
6. Откройте занятие и нажмите «Занятие проведено». Теперь его стоимость учитывается в долге. При отмене запись остается в истории, начисление исключается. Редактирование занятия из серии изменяет только его.
7. Выдайте домашнюю работу из занятия, карточки ученика или раздела «Задания». Укажите срок, описание, ссылку и при желании файл до 10 МБ. После выполнения поставьте соответствующий статус; для «Проверено» нужен комментарий.
8. В «Успеваемости» добавляйте оценки 0–100%. После двух результатов появится график по датам.
9. В «Оплатах» вручную запишите полученную сумму. Например, после проведенного урока за 800 ₽ оплата 1 000 ₽ даст аванс 200 ₽. Приложение не переводит деньги.
10. В настройках цвет и характер заголовков меняются сразу и сохраняются автоматически. Дождитесь статуса «Сохранено». При ошибке появится сообщение с кнопкой повторения. Для имени и ставки нажмите «Сохранить профиль». Новая ставка по умолчанию не переписывает ставки существующих учеников и историю занятий.

Карточка ученика объединяет занятия, задания, результаты и оплаты. Архивирование сохраняет историю и запрещает новые записи до восстановления ученика.

Быстрый поиск — поле в верхней панели. Нажмите и сразу печатайте; результаты появятся под полем. Ctrl+K или Cmd+K переводит фокус в него. Стрелки выбирают результат, Enter открывает карточку, Escape закрывает результаты. Отдельного поискового окна нет.

Каждый раздел имеет свой адрес: /overview, /calendar, /students, /homework, /progress, /finance, /settings. Кнопки браузера «Назад» и «Вперед» возвращают между разделами. Открытая карточка также попадает в историю: «Назад» закрывает ее. Адрес раздела можно добавить в закладки.

Экспорт записей JSON — в настройках. CSV взаиморасчетов — в оплатах. Вложения скачиваются из конкретного задания.
