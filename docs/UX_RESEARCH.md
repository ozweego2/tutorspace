# Решения для интерфейса TutorSpace 1.1

Обновлено 18 ноября 2026. Основа изменений — обратная связь пользователя после первой рабочей версии. Нужен спокойный современный интерфейс для одного репетитора, работающего очно по понедельникам и пятницам, со ставкой 800 ₽/час.

## Что изучено

[TutorBird — Calendar and Attendance](https://www.tutorbird.com/calendar-attendance/) показывает несколько видов расписания, поиск и фильтрацию, назначение уроков с индивидуальной ставкой ученика и работу с заметками из занятия. Для TutorSpace полезен принцип: подробности урока и действия с ним доступны из расписания, а вид календаря выбирается под задачу.

[Teachworks — Calendar](https://www.teachworks.com/features/calendar) описывает повестку дня и недели, переход к дате, фильтры и прямое изменение расписания: перетаскивание, создание занятия нажатием на календарь и действия с выбранным уроком. В TutorSpace взяты читаемый список занятий, мини-календарь для выбора даты, быстрые действия при наведении и перенос на другой день с подтверждением через форму.

Это изучение общедоступных страниц и иллюстраций продуктов, а не тестирование их закрытых аккаунтов. Внешний вид, код и изображения конкурентов не копировались. Возможности родительских кабинетов, зарплат и платежных интеграций не переносились: для личной практики они перегрузили бы интерфейс.

## Что изменено

| Затруднение в первой версии | Решение |
|---|---|
| Цвет менялся только после сохранения, большая часть панели оставалась зеленой | Мгновенное применение всей палитры, автоматическая последовательная запись и явный статус сохранения |
| Авторизованный посетитель сразу попадал в расписание | Корневой адрес открывает проверку подключения, затем отдельный экран входа; после подтверждения открывается главная |
| Назад в браузере уводило со всего приложения | У каждого раздела свой адрес; карточки имеют адрес с идентификатором и закрываются через историю назад |
| Для поиска требовалось открыть отдельное окно | Поле находится в верхней панели; результаты показываются под ним при фокусе и вводе |
| Сетка месяца была слишком плотной | По умолчанию показан список ближайших уроков с большими временем, учеником, темой и стоимостью |
| Повторяющиеся демонстрационные темы выглядели как реальные уроки | Пример отделен от рабочего пространства и явно помечен; ранее созданные записи не удалены |
| Наведения не помогали выполнять работу | При наведении доступны действия с уроком, подсветка следует за указателем внутри строки, есть перетаскивание в месяце |
| Нижние пункты меню могли не помещаться на невысоком экране | Необязательная карточка скрывается, меню допускает прокрутку, настройки доступны в верхней панели |

## Вход и сохранение доступа

Сохранен настоящий платформенный вход через ChatGPT. TutorSpace не собирает пароль и не имитирует самостоятельную регистрацию. Если аккаунт уже авторизован у провайдера, на экране входа показан найденный аккаунт, а повторный пароль не требуется. Приватный доступ к сайту сохранен.

## Движение и курсор

Реакции сосредоточены на рабочих элементах: строка занятия подсвечивается в точке наведения, появляются быстрые кнопки, месяц показывает место переноса и краткую подсказку. Изменение даты не сохраняется незаметно: открывается форма с новым временем. У этих действий есть обычные кнопки и клавиатурный фокус. Глобального следа за курсором и декоративных непрерывных движений нет. Системное предпочтение уменьшенного движения учитывается.
