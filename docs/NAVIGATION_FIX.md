# Исправление переходов TutorSpace 1.1.1

На опубликованной сборке воспроизведено: нажатие «Ученики» оставляло адрес /calendar без изменения. В консоли возникала ошибка TypeError: e is not a function внутри перехода компонента Link библиотеки Vinext. Сбой проявлялся в сборке для публикации; проверка прямого открытия адресов и разработки его не обнаруживала.

Разделы теперь используют обычные ссылки браузера. Каждая страница самостоятельно проверяет сессию и передает в интерфейс свое имя раздела. Переход не зависит от клиентского маршрутизатора. Карточки используют локальный якорь URL и историю браузера, поэтому «Назад» сначала закрывает карточку. Старые адреса с ?item также читаются.

«Мое пространство» в боковой панели и верхней строке открывает главную. Логотип также ведет на главную. Значок документа открывает отдельную страницу /about с описанием рабочих сценариев, ссылками в приложение и ответами о ставках, стоимости уроков и учебном примере.

В редакторе проведенного занятия длительность больше не меняет отображаемую зафиксированную стоимость. Для нового занятия показаны стоимость часа и длительность, чтобы отличать ставку ученика от суммы за урок.

Для проверки именно публикуемой сборки предусмотрен временный loopback-прокси work/built-preview-proxy.mjs перед локальным Worker. Он передает только тестовую личность local_seedy. Прокси не входит в исходный Git-архив, не публикуется и используется только на 127.0.0.1 во время проверки. Платформенная авторизация опубликованного сайта сохранена.

Проверено через реальные нажатия в локальной собранной версии: «Ученики», «Главная», «Задания», «Успеваемость», «Оплаты», «Расписание», верхняя ссылка «Мое пространство», профиль, страница /about и возврат браузера. После обхода шести разделов ошибок JavaScript в браузере не зарегистрировано.

В редакторе проведенного тестового урока длительность изменена с 60 на 90 минут: отображаемая зафиксированная стоимость осталась 800 ₽. Изменение отменено без записи в рабочую базу. Проверки проведены с локальным тестовым аккаунтом, данные опубликованной практики не изменялись.
