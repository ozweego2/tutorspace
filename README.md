# TutorSpace

Рабочее пространство репетитора: календарь на месяцы, ученики, банк заданий, домашние задания с вложениями, результаты, оплаты и баланс. Версия 1.4.0.

## Быстрый запуск разработки

Нужны Node.js 22.13+ и Git. Проверено на Node.js 24.20.0 в Windows.

```powershell
npm ci
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_purple_omega_flight.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_tutor_integrity.sql
npm run dev
```

Примените каждую миграцию один раз к новой локальной базе. Затем откройте адрес из вывода команды, обычно http://127.0.0.1:5173. Вход локальной разработки имитируется платформенным помощником и недоступен в продуктивной сборке. Рабочая публикация использует настоящий вход с ChatGPT.

## Проверки

```powershell
node scripts/test-tutor.mjs
node scripts/test-routes.mjs
node node_modules/typescript/bin/tsc --noEmit
npm run build
```

Тесты серверной логики используют временную SQLite в памяти и реальные обработчики API. Они не изменяют рабочие данные. Результат сохраняется в work/api-test-results.json.

## Документация

- docs/USER_GUIDE.md — пользовательские сценарии.
- docs/ARCHITECTURE.md — устройство, API и отличия от исходного ТЗ.
- docs/VERIFICATION.md — результаты проверок и ограничения.
- docs/VERIFICATION_V1_1.md — проверка исправлений по обратной связи.
- docs/UX_RESEARCH.md — изученные интерфейсы и принятые решения.
- docs/NAVIGATION_FIX.md — исправление переходов и проверка публикуемой сборки.

Схема и неизменяемые SQL-миграции находятся в db/ и drizzle/. Обработчики — app/api/. Интерфейс — app/workspace.tsx и app/globals.css. Серверный запуск — worker/index.ts. Интеграцию Sites в сборке следует сохранять.

Ключи и пароли для работы опубликованного приложения в исходниках не нужны. Исходный код не содержит локальную базу, пользовательские вложения и учетные токены. Шрифт Manrope включен локально с открытой лицензией OFL.

Хостинг объявлен в .openai/hosting.json. Повторные публикации должны использовать тот же project_id. Локальная и опубликованная базы независимы; демонстрационные данные тестовой среды не переносятся при публикации.


## Версия 1.2
Главная и расписание открывают календарь месяца. Слева — ученики: перетаскивание на дату или выбор ученика и дня открывает короткое назначение. Перенос урока сохраняет цену и длительность; применяется только к выбранному уроку. Повторы: разово, еженедельно, Пн/Пт, свои дни.

Ученик: имя, предмет, класс и ставка. Заметки доступны при редактировании. Тема (светлая/темная) и акцент сохраняются в аккаунте; быстрый переключатель находится в верхней панели.

Миграция `0002_yellow_mesmero` добавляет предмет и тему, архивирует только записи с явной меткой демонстрационного ученика и отменяет их уроки. Данные настоящих учеников сохраняются. Демонстрационный режим больше не доступен.


## Версия 1.3
Главная — ближайший урок, следующая тема по каждому ученику, работы к проверке, невыданная домашка и уроки без отметки. Расписание — календарь и назначение.

Повторения выбираются по дням недели и интервалу 1/2 недели, до указанной даты. При переносе одного запланированного урока можно изменить ученика, время и длительность. Новая длительность или новый ученик пересчитывают цену; простой перенос даты сохраняет цену. Выданную работу нельзя передать другому ученику; неподготовленный черновик при смене ученика очищается.

Готовые планы математики 7–11 классов и базовой физики лежат в `lib/curriculum.ts`. Урок получает снимок темы и индекс плана. Черновик домашки создаётся в одной транзакции с уроком. Это авторские упражнения, не номера конкретного учебника. В карточке ученика можно заполнить пустые будущие уроки; уже названные темы сохраняются.

Настоящая регистрация с независимыми провайдерами пока не реализована. Текущая версия использует identity и private access платформы Sites. Подробности: `docs/ARCHITECTURE.md`.
