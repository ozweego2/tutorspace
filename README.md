# TutorSpace

[Открыть демонстрацию](https://ozweego2.github.io/tutorspace/) · [История разработки](https://github.com/ozweego2/tutorspace/commits/main/)

Учебный проект по основам проектной деятельности: рабочее пространство репетитора. Ученики, расписание, библиотека уроков, домашние задания, проверка с оценкой, успеваемость и учёт оплат.

## Две версии

**Личная версия** работает отдельно: вход через ChatGPT, записи на сервере, файлы в R2 и интеграция с Telegram после настройки бота. Публичная демонстрация к её данным не обращается. Серверные исходники сохранены в репозитории; прежнее описание находится в [документации личной версии](docs/PRIVATE-VERSION.md).

**Демонстрация для защиты** открывается по публичной ссылке без аккаунта. Здесь тот же интерфейс с вымышленными учениками и отдельным хранилищем в браузере каждого посетителя. Можно добавлять учеников, создавать и переносить занятия, готовить ДЗ, прикреплять файлы, ставить оценки, архивировать учеников и менять тему. Кнопка «Сбросить демо» возвращает исходный набор примеров.

Демо не отправляет сообщения, не принимает оплату и не синхронизирует записи между ноутбуками. Файлы хранятся в IndexedDB, остальные записи — в localStorage. Это демонстрационный режим, а не публичный доступ к личному кабинету.

## Как показать преподавателю

1. Открыть ссылку демонстрации на любом ноутбуке.
2. На главной открыть ближайший урок, затем посмотреть расписание и библиотеку.
3. Нажать «Поставить оценку за ДЗ» и сохранить результат.
4. В учениках добавить новую запись, обновить страницу и убедиться, что она сохранилась.
5. При необходимости сбросить демо перед следующим показом.

## Автоматическая публикация

После каждого push в ветку main GitHub Actions запускает проверки, собирает демонстрацию и публикует GitHub Pages. Секреты хостинга для этого не нужны. Личная версия при этом не меняется. Сборка и публикация видны во вкладке Actions.

Существующие девять коммитов разработки сохранены без переписывания и искусственных дат. Новые коммиты описывают добавление публичного режима и автоматической публикации.

## Локальный запуск

Требуется Node.js 24.

```text
npm ci
npm run test:demo
npm run build:demo
npm run preview:demo
```

Открыть адрес, который напечатает сервер. Для разработки — npm run dev:demo.

Исходный интерфейс находится в app/, демонстрационные данные и сохранение — в demo/, публикация — в .github/workflows/demo-pages.yml. Демосборка использует путь /tutorspace/ и создаёт отдельные HTML-страницы разделов, поэтому обновление страницы и кнопка «Назад» работают без серверного приложения.

Не добавлять в публичный репозиторий .env, .dev.vars, токены, локальную базу .wrangler, пользовательские вложения и экспорт личных записей. Эти пути исключены из Git.
